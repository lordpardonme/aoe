# Resume Localization And Tailoring Plan

Purpose: stop using one generic CV for every application. Every resume must be selected and tailored based on the tracker row: country/region, agency vs direct employer, sector, application channel, and available proof from the evidence bank.

## Core Rule

There is no single universal resume.

Use the master CV only as a source library. For every application, create the final resume from:

1. Target country norms
2. Company or agency type
3. Sector and role focus
4. Application channel
5. Evidence we can truthfully prove

Do not add `Open to relocate to Dubai, UAE` unless the target is Dubai/UAE/GCC or the application specifically needs relocation clarity. For Japan, Canada, US, UK, Europe, Australia, India, remote, or global roles, use location language appropriate to that market.

## Worldwide Country / Region Format Rules

Treat these as defaults, not permanent laws. Before applying, verify the job post, company careers page, ATS portal fields, recruiter instructions, and local hiring custom for that specific target.

### UAE / Dubai / GCC

Default format:

- ATS-safe PDF.
- 1-2 pages depending on experience density and role seniority.
- No photo by default for ATS/company portals.
- Keep nationality, DOB, marital status, passport, visa status, and photo out unless the job post or recruiter explicitly asks.
- Add location/relocation line only when helpful: `Open to relocate to Dubai, UAE` or `Open to UAE relocation`.
- Emphasize sectors common in UAE hiring: fintech, B2B SaaS, logistics, operations, healthcare, real estate, energy, enterprise dashboards.

Use for:

- UAE direct employers.
- UAE agencies.
- GCC-facing agencies.

### United States / Canada

Default format:

- Resume, not long CV.
- 1 page preferred; 2 pages acceptable when experience is highly relevant.
- No photo.
- No age, marital status, religion, nationality, passport, DOB, or unrelated personal details.
- Strong ATS structure: summary, experience, education, skills.
- Quantified achievements and role-specific keywords.

Location language:

- Use current location only if needed.
- If visa/relocation is an issue, clarify separately only when asked by employer or job post.

### United Kingdom / Ireland

Default format:

- CV, usually 1-2 pages.
- No photo.
- No DOB, marital status, religion, or unnecessary personal details.
- Portfolio link is important for design roles.
- Keep tone direct and evidence-led.

### European Union / EEA

Default format:

- Country-specific decision required.
- No-photo ATS version is safest for international tech/product applications.
- Europass may be acceptable for public-sector, academic, mobility, or formal EU applications, but not always best for startup/product roles.
- Some markets culturally tolerate photos, but do not include a photo unless the country/company/application channel favors it.

Country notes:

- Germany/Austria/Switzerland: photo may be culturally common in traditional applications, but optional; for tech/ATS, no-photo version is safer unless requested.
- France/Spain/Italy: photo sometimes appears in local CVs; verify job/channel before adding.
- Netherlands/Scandinavia: no-photo, concise, skills/outcomes-led is safer.

### Japan

Default format depends on application channel:

- For Japanese-local hiring process: prepare `Rirekisho` plus `Shokumu Keirekisho`.
- Rirekisho is structured/personal-history style and commonly includes a photo.
- Shokumu Keirekisho is the detailed work-history document closer to a professional CV.
- For global tech companies in Japan, especially English-language roles, use a clean English resume first unless the employer asks for Japanese documents.

Location language:

- Do not write Dubai relocation.
- Use Japan-specific relocation/work authorization language only after checking the job post.

### Australia / New Zealand

Default format:

- Resume, usually 1-2 pages.
- No photo.
- No age, marital status, religion, nationality, or unrelated personal details.
- Outcome-led bullets, clear skills, portfolio link.

### Singapore

Default format:

- 1-2 page resume/CV for product/design roles.
- No photo by default for multinational, tech, banking, SaaS, and ATS applications.
- Include portfolio link, current location, and work authorization/relocation only if relevant.
- Keep personal details limited. Do not add nationality, race, religion, marital status, or DOB unless a portal explicitly asks.

### Malaysia

Default format:

- 1-2 page CV.
- Photo can appear in some local templates, but no-photo ATS version is safer for tech/product roles and multinational companies.
- Include portfolio link and role-specific skills.
- Mention relocation/work authorization only if the employer needs it.

### Indonesia

Default format:

- 1-2 page CV for tech/product roles.
- Photo is common in some local CVs, but no-photo ATS/company-portal version is safer unless requested.
- Keep structure simple: profile, work experience, education, skills, tools, portfolio.
- Localize language only if the job post is Bahasa Indonesia or explicitly local-market facing.

### South Korea

Default format:

- For local Korean hiring, applications may use company forms and can request personal details or photo.
- For international tech roles or English-language roles, use no-photo ATS resume first.
- Do not add Korean-local personal details unless the application form requires them.
- If applying to a Korean company with a local process, verify whether a Korean-form resume, Korean language version, or photo is expected.

### China / Hong Kong / Taiwan

Default format:

- For international product/tech companies, use no-photo ATS resume.
- Local Chinese CVs may sometimes include photo and more personal detail, but this should be added only when requested or clearly normal for the application channel.
- For mainland China roles, check whether Mandarin CV, local phone/address, visa/work authorization, or WeChat/contact details are expected.
- Hong Kong is closer to UK-style CV norms for many professional roles: concise, no unnecessary personal details, portfolio for design.

### Brazil / LATAM

Default format:

- 1-2 page CV.
- No photo by default for multinational, remote, product, SaaS, and ATS roles.
- For Brazil, Portuguese version may be needed when the role is local-market or Portuguese-language.
- Use `CV` wording more than `resume`.
- Emphasize remote collaboration, product outcomes, and sector fit.

### Russia / CIS

Default format:

- 1-2 page CV/resume.
- Photo can be common on some local job boards, but no-photo ATS/global-company version is safer unless requested.
- Check whether Russian-language CV is required.
- For international/remote companies, use global ATS format.

### Middle East Beyond UAE

Default format:

- GCC countries often accept CV wording and 1-2 pages.
- No photo by default for ATS/company portals unless requested.
- Agency/recruiter channels may tolerate more personal/location context, but avoid passport, DOB, marital status, and photo unless needed.
- Localize relocation line to the country: Saudi Arabia, Qatar, Kuwait, Bahrain, Oman, UAE.

### Africa

Default format:

- Use country-specific check.
- South Africa and multinational roles: no-photo, 1-2 page ATS-style CV is generally safer.
- Some local markets may accept photos or longer CVs, but only add when the post/channel expects it.
- For remote/global roles, use the global no-photo version.

### Global / Unknown Country

Default format:

- No photo.
- 1-2 pages.
- No unnecessary personal details.
- ATS-safe PDF.
- Standard headings.
- Portfolio link visible at top.
- No relocation line until target country is known.

Use this when the tracker row says:

- Worldwide / Remote
- Global
- Unknown
- Multiple regions
- Company is multinational and application country is unclear

### India

Default format:

- 1-2 page resume/CV.
- Photo usually not needed for product/design tech roles.
- Current city can stay.
- Add relocation only when applying outside current city and the employer needs it.

### Remote / Worldwide

Default format:

- ATS-safe global resume.
- No photo.
- No country-specific personal details.
- Clarify time-zone overlap, remote collaboration, async tools, and global product/team experience if relevant.

## Tracker Decision Tree

For every tracker row:

1. Read `Country / Region`.
2. Read `Type`: Agency, Direct Employer, Form, LinkedIn Search, Phone / WhatsApp Lead.
3. Read company sector from notes, website, job post, or agency specialization.
4. Decide country format:
   - UAE/GCC format
   - US/Canada format
   - UK/Ireland format
   - EU country-specific format
   - Japan format
   - Australia/NZ format
   - Singapore format
   - Malaysia format
   - Indonesia format
   - South Korea format
   - China/Hong Kong/Taiwan format
   - Brazil/LATAM format
   - Russia/CIS format
   - Africa country-specific format
   - India format
   - Remote/global format
5. Decide channel format:
   - ATS portal: simplest PDF, no photo, standard headings.
   - Recruiter email: ATS PDF plus stronger human-readable summary.
   - Agency inbox: broader sector-matched CV, not one-company-specific.
   - Direct employer: company/role-specific CV.
   - LinkedIn/manual outreach: short CV plus message angle.
6. Decide sector angle:
   - Fintech / payments
   - B2B SaaS / dashboards
   - Operations / logistics / fleet
   - Healthcare / booking
   - Marketplace / search/catalog
   - Real estate / proptech
   - Energy / fuel / field operations
   - Enterprise/internal tools
7. Pull only truthful evidence from the evidence bank.
8. If evidence is missing or weak, ask the user before inventing.

## Ask The User When Stuck

Ask before adding a claim if:

- The role requires a sector not covered in the evidence bank.
- The company needs a specific domain claim, e.g. banking compliance, Japanese market, B2B procurement, AI products, real estate transactions, ERP, CRM, supply chain, Web3, insurance, aviation, hospitality.
- The job requires leadership, mentoring, people management, design strategy, or ownership that is not already documented.
- The resume would benefit from an achievement metric that is not in the evidence bank.
- The application country requires a format detail that is uncertain, e.g. photo, local address, visa status, language level, or Japanese-format documents.

Question format:

`For [company/role], I need to know whether you have real experience with [domain/task]. If yes, tell me what you did, product name, impact/metric if any, and whether it shipped.`

## Master CV Usage

The master CV is not the sendable default.

Use it as:

- Evidence library.
- Base text for role variants.
- ATS-safe structure reference.
- Starting point for a country/sector-specific resume.

Before sending any resume:

- Remove irrelevant sectors.
- Reorder bullets around the target role.
- Localize contact/location line.
- Re-score ATS fit.
- Show the packet before sending.

## Resume Family To Maintain

Maintain resume variants as families, not one-off random files:

- `global-ats`: no photo, 1-2 page, standard ATS format for unknown/global/remote/company portals.
- `uae-gcc-ats`: UAE/GCC focused, relocation line only when relevant, agency/direct-employer variants.
- `japan-local`: Japan-specific path with `rirekisho` + `shokumu keirekisho` when needed.
- `europe-ats`: no-photo European product/tech CV, with country-specific adjustments.
- `north-america`: US/Canada no-photo resume, concise and achievement-heavy.
- `apac-localized`: Singapore, Malaysia, Indonesia, South Korea, China/HK/Taiwan variants after target check.
- `latam-localized`: Brazil/LATAM variants, Portuguese/Spanish only when needed.
- `agency-broad`: sector-matched but not overfit to one company.
- `direct-company`: tightly matched to one company/JD.

## Source Notes From Research

- Government of Canada Job Bank advises clear, concise resumes, tailoring to each position, quantifying achievements, limiting to two pages, leaving out unnecessary personal details, and not including a picture in Canada.
- Europass exists as an EU skills/CV transparency framework and can be useful for some European mobility/public-sector/formal applications, but it is not automatically the best product-design resume format.
- Japan commonly distinguishes between `rirekisho` and `shokumu keirekisho`; local-process applications can require a Japanese-style structured resume and detailed work-history document.
